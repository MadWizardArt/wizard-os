# Reviewed Etsy title edits

Use `preview_etsy_listing_title` and `apply_etsy_listing_title` for existing draft
or active digital/physical listings. Existing records must already be linked;
import manually created drafts first when necessary. No new listing is created.

1. Read `get_product` and select its fulfillment and saved Etsy listing ID.
2. Aurelia proposes an accurate title from canonical product/listing facts. Call
   preview with `productId`, `fulfillment`, `expectedEtsyListingId`, and `newTitle`.
3. Show the exact preview, including old canonical title, observed Etsy title,
   new title, active/draft state, word count and character count for approval.
4. Call apply with `productId`, that `previewId`, and `confirmTitleChange:true`.
   The ten-minute approval is checked against current canonical and Etsy state.
5. Read the returned verification and product journal. A title-only operation
   does not establish full listing, supplier, image or visual verification.

Canonical listing intent is committed before Etsy mutation; the internal product
name remains unchanged. The dedicated transport uses the official `updateListing`
PATCH endpoint with `listings_w`, form encoding, and **only the title key**.
Descriptions and required AI disclosure, tags, taxonomy, inventory, prices,
images, supplier mappings and publication state are never supplied as updates.
Readback verifies the exact title, same state and stable metadata fingerprint;
server timestamps and engagement counters are excluded. Other fields that change
independently may require review rather than a success assertion.

Write access uses the existing commerce write-mode gate. There is no publication
operation. Durable SENDING evidence precedes the request. Unknown network or DB
finalization outcomes return NEEDS_REVIEW and retain canonical intent. Same-preview
retries verify current state only; they never blindly resend. A fresh preview and
approval authorize another attempt. Completed retries return historical evidence.
Canonical title intent can differ from Etsy while an operation needs review; this
is surfaced explicitly. Old titles and approved preview remain in the journal.

Validation accepts 1–140 characters without trimming or truncating the approved
text and follows the API's supported-character and limited-punctuation rules.
Etsy's current title guidance recommends clear item names, key distinguishing
traits, little repetition, and considering fewer than 15 words. The word count is
advisory, not a hard limit or SEO score. No keyword-volume, ranking or accuracy
claim is generated by the transport. Aurelia and the owner review the wording.

Source: https://www.etsy.com/seller-handbook/article/1399426136697
API: https://developers.etsy.com/documentation/reference/#operation/updateListing

Tests cover active digital and draft physical edits, title validation, preview
preservation, canonical/remote drift, expiry, disabled writes, ownership/type,
title-only HTTP payload, durable intent, uncertain outcomes, rollback and retries.
The coding session performs no live Etsy title edits.
