# Wizard OS

Wizard OS is Brandon's private operating system for artwork, campaigns, inventory, Council operations, and related studio workflows.

Current product areas include the Crucible dashboard, artwork lifecycle, Campaigns/Calendar, Warlock/Etsy scaffolding, and the Nine Muses Museum.

## Grotto development

The Grotto is being introduced as a separate, quiet image-first space beneath the Museum. Its first implementation is Tessa-first and uses the existing Artist Gate for access. Generated gallery images are stored privately through authenticated application routes rather than committed to the public repository. Civitai generation remains feature-gated until the private orchestration token and Tessa LoRA AIR are configured in the deployment environment.
